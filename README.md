# サッシ呼称チェッカー

サッシの呼称（例：`16520`）を入力するだけで、そのサイズが実在するかを確認できるツールです。
YKK AP APW430 / APW330 と LIXIL TW（それぞれ通常・防火）に対応しています。

**公開URL：https://harutong08.github.io/sash-code-checker/**

Claudeアカウントなど一切不要、リンクを開くだけで誰でも使えます。


## 使い方

### 1. メーカーと区分を選ぶ

- メーカー：YKK AP APW430 / APW330 ／ LIXIL TW
- 区分：通常サッシ ／ 防火サッシ

同じ呼称でも、メーカー・区分が違うと結果も変わります。

APW430とAPW330のように同じメーカー内に複数シリーズがある場合は、「シリーズで絞り込む」プルダウンで
どちらかに絞り込めます（絞り込まなければ両方まとめて表示されます）。

### 2. 呼称で調べる

「サッシ呼称」欄に番号を入力するだけです。

- 例：`16520`
- 例：`F16520`（頭に記号を付けると窓種を絞り込めます）

| 記号 | 窓種 |
|---|---|
| F | FIX窓 |
| S | すべり出し窓 |
| T | たてすべり出し窓 |
| AW | 引違い窓 |
| TF / SF | FIXとの組み合わせ（段窓） |
| TR / SR | 複数枚の組み合わせ（連窓） |

※記号を付けなくても検索できます。

※LIXIL TWの一部の呼称には、末尾に `M`（マドタイプ）・`A`／`B`（2×4など段差違い）が付きます。
　例：`02118M`、`03618A` のように、末尾のアルファベットも含めてそのまま入力してください。

### 3. 番号が分からないときは選ぶだけでもOK

「または、サイズから選ぶ」で、幅→高さをプルダウンで選べば呼称が分かります。
（実寸(mm)でも呼称でも選べます）

### 4. 複数まとめて調べたいとき

「まとめてチェック」タブへ。図面の呼称一覧をそのまま貼り付けて「まとめて判定」を押すだけです。

### 5. 結果の見方

- カード左の図：斜め線＝開き方、色付きの縁＝通常（緑）／防火（赤）
- 「あり」→ その規格は実在します（窓種・サイズ・カタログ頁つき）
- 「なし」→ 存在しません（似た番号があれば候補を出します）

### 困ったときは

画面下の「呼称の読み方」に、番号の仕組みと出典カタログが書いてあります。
**最終確認は必ずカタログ本紙で行ってください。**


## アプリとしてインストールする

このサイトはPWA（インストール可能なWebアプリ）として作られています。

| 環境 | 手順 |
|---|---|
| Windows（Chrome/Edge） | サイトを開く → アドレスバー右側の「インストール」アイコン、または「…」メニュー→アプリ→このサイトをインストール |
| Android（Chrome） | サイトを開く → 「ホーム画面に追加」／「アプリをインストール」 |
| iPhone（Safari） | サイトを開く → 共有ボタン → 「ホーム画面に追加」 |

インストール後もアイコンをタップするたびに最新版を読みに行くので、**更新のたびに入れ直す必要はありません**。


## 技術構成

- 単一の `index.html`（HTML/CSS/JSと全データを内包した自己完結ファイル、外部通信なし）
- `manifest.json`：アプリ名・アイコン・単独ウィンドウ表示の設定
- `sw.js`：サービスワーカー。オンライン時は常に最新を取得し、オフライン時のみキャッシュにフォールバック
- `icons/`：アプリアイコン（192px・512px）
- ホスティング：GitHub Pages（`main`ブランチのルートを配信）

データはYKK AP・LIXILの各商品カタログのページを直接確認しながら手作業で登録しています
（掲載頁はカード内に表示、出典はページ下部の「呼称の読み方」を参照）。


## 更新のしかた

1. `index.html` を編集する
2. コミットして `main` ブランチへ push する
3. 数十秒〜1分ほどでGitHub Pagesに自動反映される（`manifest.json` や `icons/` を変えたときも同様）

公開URL・インストール済みアプリのショートカットは変わらないため、利用者側の操作は不要です。
